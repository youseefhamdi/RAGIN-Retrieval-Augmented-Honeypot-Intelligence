## Objective
Fix `LightRAGAdapter` storage initialization bug (never called `initialize_storages()`), stabilize the test suite by partitioning integration tests that require an LLM gateway, and achieve a clean 33/33 unit test pass.

## Important Details

- Fix: added `_ensure_all_initialized_sync()` and `_ensure_all_initialized_async()` helpers; all public methods now call the appropriate init helper first
- Test suite partitioned: **38 collected, 5 deselected** (integration/slow), **33 selected, 33 passed**
- Integration/slow tests marked with `@pytest.mark.integration @pytest.mark.slow` — hang without a running LLM gateway at `http://localhost:8080`
